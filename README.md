# Show Rumba Latina - Sitio Web Oficial

Portal web de alta conversión y presencia artística para la agrupación musical **Show Rumba Latina** (Huancayo, Perú), bajo la dirección de **Jesús Rojas Ochoa**.

Diseñado bajo estándares Mobile-First, optimización SEO local para Google, paleta dorada/escénica y cotizador interactivo directo a WhatsApp.

## 🚀 Tecnologías & Arquitectura ($0.00 de Costo)
* **Frontend:** Vite + Tailwind CSS + Vanilla JavaScript modular (0 demora de hidratación, carga ultra-rápida < 1s).
* **SEO Local & Rich Snippets:** Metadatos OpenGraph y Schema.org JSON-LD tipo `MusicGroup` geolocalizados en Huancayo.
* **Cotizador WhatsApp:** Formulario inteligente que autocompone mensajes detallados codificados para WhatsApp Web y WhatsApp Móvil.
* **Despliegue GitHub Pages:** Compilación local en CPU y subida a la rama `gh-pages` a costo $0 sin consumir minutos de GitHub Actions.
* **Ruta Universal:** Configuración `base: './'` que permite ejecutar la web indistintamente en la raíz de un dominio (`https://showrumbalatina.github.io`) o en una subcarpeta (`https://darckrovert.github.io/showrumbalatina/`).

---

## 🛠️ Comandos de Desarrollo
```bash
# Iniciar servidor de desarrollo en vivo
npm run dev

# Compilar para producción (genera /dist optimizado)
npm run build

# Desplegar localmente a la rama gh-pages en GitHub
npm run deploy
```

## 🌐 Cómo Habilitar `https://showrumbalatina.github.io`
El nombre de usuario/organización `showrumbalatina` está actualmente **libre y disponible** en GitHub:
1. Crea una Organización gratuita en GitHub llamada `showrumbalatina` (en [github.com/organizations/new](https://github.com/organizations/new)).
2. Crea el repositorio `showrumbalatina.github.io`.
3. Ejecuta `npm run deploy` apuntando a dicho repositorio y GitHub Pages activará la URL directa `https://showrumbalatina.github.io` de inmediato.
